# AI 使用情况

本文件只说明这个仓库里第 1 阶段代码的实际来源，供以后写实验报告时核对。它不是小组分工表。

阶段 1 的词法分析器、构建文件、回归夹具和 `docs/` 说明，是仓库所有者在 Cursor 云端代理中让 Grok 根据下列材料编写的：

- 所有者已经从课程页面提取的阶段 1 正文快照
- 阶段 1 补充格式
- 阶段 2/3 正文里与注释有关的两句，只用于补快照中的空列表
- 作业参考资料给出的公开文档

代理没有登录课程平台，没有提交评测，没有创建、读取或写入 GitHub 访问令牌。平台要求的令牌由提交人自己填写。

课程要求按组完成，答辩材料也要求真实贡献。这个仓库里没有其他成员的提交，不能从这里编出四人或五人的模块分工、人工编写比例或并不存在的提交记录。报告里的成员和贡献必须按组里实际发生的工作另写。

AI 生成的部分包括扫描器、输出格式、测试夹具和这份说明。负号没有按通用 C 词法自动从整数里去掉；实现前对照了原题样例 token 98–100，取舍写在 `README.md` 和 `docs/design.md`。本地 `make test` 通过只表示夹具与程序一致，不表示平台评测已经通过。
