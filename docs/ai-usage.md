# AI 使用情况

本文件只说明这个仓库里代码的实际来源，供以后写实验报告时核对。它不是小组分工表。

阶段 1 的词法分析器和阶段 2 的语法分析、语义分析、回归夹具和 `docs/` 说明，是仓库所有者在 Cursor 云端代理中让 Grok 根据下列材料编写的：

- 所有者已经从课程页面提取的阶段 1、阶段 2 正文和答辩细则
- 阶段 1 补充格式，以及平台词法验收结果
- 作业参考资料给出的公开文档，只在原文没有写清库函数和 `const` 赋值时作补充，并在设计记录里标明

代理没有登录课程平台，没有提交评测，没有创建、读取或写入 GitHub 访问令牌。平台要求的令牌由提交人自己填写。

课程要求按组完成，答辩材料也要求真实贡献。这个仓库里没有其他成员的提交，不能从这里编出四人或五人的模块分工、人工编写比例或并不存在的提交记录。报告里的成员和贡献必须按组里实际发生的工作另写。

AI 生成的部分包括扫描器、递归下降语法分析、语义检查、内部语法树、测试夹具和说明。阶段 1 的负号取舍对照了原题样例 token 98–100，并已被平台 100/100 验收，检查点是 `57b262ef8becd948cc9b28aecb26382a6bd6c581`。阶段 2 允许 `int b;` 不初始化，因为文法和示例一与“必须初始化”那句话冲突。本地 `make test` 通过只表示夹具与程序一致。阶段 2 还没有平台成绩。
