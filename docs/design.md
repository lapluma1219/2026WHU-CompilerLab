## 模块

`compiler` 只有一个入口 `src/main.cpp`。它检查命令行，把标准输入整段读入，调用 `toyc::Lexer`，再按评测格式写 stdout。

`src/lexer` 不打印。`tokenize()` 返回 token 序列和诊断，供以后的语法分析重复使用。token 保存 0-based 行号和列号；`-token` 模式不打印列号。

内部类别用 `TokenKind`。屏幕上的类型名只由 `token_type_name` 产生：`Ident`、`IntConst`，或其他 token 的 `'字面量'`。

## 扫描顺序

1. 把 `\r\n` 和单独的 `\r` 规范成 `\n`。
2. 跳过空格、`\t`、`\n` 和注释。
3. 标识符按 `[_A-Za-z][_A-Za-z0-9]*` 尽量延长，再全文查关键字。
4. 数字取最长连续十进制数字。`012` 是一个 `IntConst:"012"`，不是 `0` 再加 `12`。字母会截断数字，所以 `0a` 仍是 `IntConst:"0"` 和 `Ident:"a"`。
5. 双字符运算符只在第二个字符确实构成 `<=`、`>=`、`==`、`!=`、`&&`、`||` 时取长匹配。
6. 其余字符记一条诊断并前进至少一个字节；合法 UTF-8 码点整段跳过。然后继续扫描。

关键字判断必须在移动字面量字符串之前完成。参数求值顺序不确定，不能写成 `add_token(classify_identifier(lexeme), std::move(lexeme), ...)`。

## 负号

课程页面正则是 `-?(0|[1-9][0-9]*)`。最长匹配会让 `-1` 变成 `IntConst:"-1"`。

综合样例源码 `b = +a - -1;` 的公布输出是：

```text
96:'+':"+"
97:Ident:"a"
98:'-':"-"
99:'-':"-"
100:IntConst:"1"
```

第二个 `-` 与 `1` 相邻，样例仍把它们拆开。若实现成一个 `IntConst:"-1"`，这一段样例会失败。

词法不能看左边是运算符、括号还是行首。实现因此在所有位置都把 `-` 做成运算符，`IntConst` 不含符号。`+1` 同样是 `'+'` 和 `IntConst:"1"`。`1-2` 是两个整数夹一个 `'-'`，不是 `IntConst:"1"` 和 `IntConst:"-2"`。

公开参考文档也要求 `-3` 输出 `'-'` 和 `IntConst(3)`，但它改写了正则，不能代替课程页面原文。第一次评测后，这个取舍不再只是样例和正则的对照：`l11_unary`、`l18_operator_adjacency` 和 `l10_mixed` 都已通过。把负号并进整数会改变这些点可能覆盖的输出，也会改变公布样例 token 98–100。因此第二次修正没有改负号。

## 前导零

第一次实现按正则的最长合法前缀切分：`0` 匹配 `(0|[1-9][0-9]*)`，`012` 整段不匹配，于是输出 `IntConst:"0"` 和 `IntConst:"12"`。参考文档算法 3 也是这样写的，并注明不要把 `012` 当成一个 NUMBER。

平台 30 个点里只有 `l04_numbers` 失败，结论是“错误输出”，没有给出输入和差异。已通过的点覆盖关键字、运算符、界符、标识符、注释、空白、一元运算符、相邻运算符、非法字符和综合片段。会单独改变数字 token、又碰不到这些点的输入，就是前导零和超长数字。

第二次实现把一段连续数字收成一个 `IntConst`，字面量保持源文件里的写法。`007`、`08`、`2147483648` 和更长的数字都如此。这不满足正则 `(0|[1-9][0-9]*)` 对 `012` 的描述，也和参考文档的切分相反。选择它，是因为平台已经否定了切分结果，而把前导零改成 `reject` 会在接受类测试里引入作业页没有规定的诊断。

超出 32 位有符号范围的数字仍然输出 token，不产生 `reject`。作业把 32 位约束写在语义部分；词法输出要求保留原文。若下一轮 `l04_numbers` 仍失败，范围诊断才是下一处要核对的行为。

## 诊断

非法字符的原因形如 `illegal character '$'`。不可打印字节使用 `illegal character U+000B` 这类写法。作业说明原因措辞不要求与示例逐字相同，行号和恢复后的 token 流要一致。

未闭合块注释来自公开参考文档算法 4 和它的自测表，不来自作业页正文或补充格式。诊断行是 `/*` 的 0-based 行，原因是 `unterminated comment`。从 `/*` 到 EOF 都算注释，其中的非法字符不另报。若平台不要这条诊断，应删掉 `skip_trivia` 里未闭合时的 `add_diagnostic`，并改 `tests/cases/unterminated_comment` 与 `unterminated_slash_star_slash`。

没有问题时不输出 `reject`，也不多打印空行。有诊断时，诊断块和 token 流之间固定一个空行；token 流为空时这个空行仍保留。

## 退出码

非法字符和未闭合注释返回 0。公开参考文档写明不得因为非法字符崩溃或非零退出。补充格式没有写退出码。命令行不是 `-token` 时返回 2，避免把未实现的阶段 2/3 模式误当成词法输出。
