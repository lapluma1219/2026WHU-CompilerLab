## 初始化矛盾

语义条文写“每个变量声明必须带有初始化表达式”。文法是 `'int' ID [ '=' Expr ] ';'`，方括号表示初始化可选。示例一有 `int b;`，输入示例是：

```bash
echo "int main() { int a; a = 1; return a; }" | ./compiler -ast
```

示例一的规定输出是 `accept`。因此 `int` 声明可以没有初始化。`const int` 的文法没有方括号，必须有 `=`。

未初始化的 `int` 可以先赋值再使用，示例一就是这样。原文只要求“使用发生在声明之后”，没有要求编译期证明每次读取前都已赋值。`int main(){ int a; return a; }` 在本地按 `accept` 处理。这不是漏检，是按文法和样例而不是按那句互相冲突的语义文字。

## 平台第二次结果与错误恢复

语法分析 92/100，25 点里 `s04_unclosed_block` 和 `s05_while_without_condition` 为“错误输出”。平台没有给出输入和期望行号。下面是对照阶段二样例和参考文档后的恢复规则，不是按测试点名字写死的输出。

- 行号是发现错误时当前 Token 的行。文件结束处没有 Token，用扫描结束后的位置：源文件最后如果有换行，这个位置在下一行。因此

```text
int main() {
return 0;
```

末尾有换行时，缺少 `}` 报在空行所在的那一行，而不是 `return` 那一行。没有换行时，报在 `return` 所在行。

- 每个没有遇到 `}` 的块各报一次。嵌套两层都没闭合，就有两条相同的 EOF 行号。内层块会先吃掉后面的语句，第一个 `}` 关闭的是内层；这和示例二里在 `void` 处报告外层缺少 `}` 是同一种规则。
- `while` / `if` 后面没有条件时只报一条：没有 `(` 且后面不是表达式，报 `Lack of '('`；有 `(` 但里面不是表达式，报 `Lack of expression`，并同步到对应的 `)`，所以 `while (;)` 不会把分号当成循环体、再把右括号留在块外面。`while a = 1;` 这种赋值不会被拆成条件。`if z == 50)` 仍只报 `Lack of '('`。条件已经解析出来但没有 `)`，仍只报 `Lack of ')'`。`while ()` 紧挨着块结束时，不再额外报一条“缺少语句”。
- 参考文档写明语法通过之后才做语义检查。存在语法错误时不再追加 `missing return` 之类的语义诊断，避免一个未闭合块或一个空 `while ()` 带出第二条行号。已经通过的语义测试本身没有语法错误，语义检查照旧。

隐藏输入没有看到，所以不能证明平台的 `s04`/`s05` 就是上面某一种写法。若复测仍失败，需要平台给出的行号序列才能区分“报在 `{` 所在行”和“报在 EOF 行”。

## 其他判断

- 负号仍是一元运算符，不进入 `IntConst`。`a - -1` 的树是减法，右子树是一元负号。
- 连续数字仍是一个 `IntConst`，与已经验收的词法行为一致。
- `else` 属于最近的 `if`。
- 关系运算符按文法左结合，`a < b < c` 语法上合法，不做额外禁止。
- 赋值只接受语句 `ID '=' Expr ';'`。`a = b = 1` 不是表达式，按语法错误处理。
- 函数只能出现在全局。调用必须写在被调函数声明之后；函数体里调用自己算递归，允许。
- 预置 `int getint()` 和 `void putint(int)`。作业示例一调用 `putint`，参考资料说明这两个库函数由语义分析预置。
- 形参和函数体最外层局部变量同一作用域，所以 `int f(int a){ int a; ... }` 是重复定义。内层 `{}` 才新建作用域。
- `const` 不能再赋值。原文没有单独写这句话，但语句语义写明与 C 一致，参考资料也写了声明后不能赋值。
- `break` / `continue` 只能出现在循环里。
- `int` 函数必须每条可能路径都 `return` 一个值。`while` 的条件若能折成非零，且循环体一定会返回、又没有 `break`，算这条路径已经返回。条件不能折成常量时，不把循环当成必然返回。
- `void` 函数可以没有 `return`；有 `return` 时不能带值。`void` 调用可以单独作为表达式语句，不能当条件、赋值右值或其他需要值的运算对象。
- 除数是常量 0 时报错，包括 `%`。`&&` / `||` 的左操作数能折成短路值时，不分析右侧，因此 `1 || 1/0` 和 `0 && 1/0` 接受。非常量除数不报错。
- 字面量超出 32 位不在本阶段拒绝。折叠只用能放进 32 位的值；`-2147483648` 由一元负号和字面量 `2147483648` 组成，折叠为 32 位最小值。有符号溢出不单独报错。
- 不检查“先赋值再读取”。不检查不可达代码。
